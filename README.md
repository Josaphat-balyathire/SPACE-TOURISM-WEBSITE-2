### What I learned

While building this particular project , i have to admit that i have learned so many thing . 
first i built it based on my own resolution , but honestly it was not satisfying at all.

this is where i watched kevin powell's course on scrimba building a long side with him. i felt confortable anough and decided to rebuild the entire website from the scrach based on my own decision about the structure of the content without looking at kiven's code. brief here is the list of all the thing that i have learned.
1 How to use utility classes and undertanding their purpose.

2 learned the @support for the first time which is usefull for providing a better user experience based on the browser support.

2 How javascript can be powerfull anough to update different content in the same page reflecting the feeling of changing the page while staying on the same one.
